# Logos

- `pajaro-icon.svg` — Ícono de app: pájaro `brand-sol` sobre cuadrado `brand-cielo` (radio 22.5%). Favicon, app stores, redes.
- `pajaro-lockup-light.svg` — Pájaro `brand-cielo` + «pájaro» en `ink` con tilde `brand-cielo`. Sobre `surface`, `surface-raised` o blanco.
- `pajaro-lockup-dark.svg` — Pájaro `brand-sol` + «pájaro» blanco con tilde `brand-sol`. Sobre `brand-cielo` o el tema Noche.
- `pajaro-wordmark-ink.svg` — Logotipo en `ink` con tilde `brand-cielo`, para fondos claros.
- `pajaro-wordmark-white.svg` — Logotipo blanco con tilde `brand-sol`, para cielo u oscuro.
- `pajaro-mark-cielo.svg` — Pájaro solo en `brand-cielo`, para fondos claros.
- `pajaro-mark-sol.svg` — Pájaro solo en `brand-sol`, solo sobre `brand-cielo` u oscuro.

Todos son SVG de color fijo (no heredan `currentColor`); para un pájaro que cambie de color usá el componente `Mark`.
