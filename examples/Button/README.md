# Button

Botón de acción en tres variantes: `primary` (relleno `cielo`, una vez por vista), `secondary` (borde `line-strong`, la acción alternativa) y `ghost` (texto `cielo`, acciones terciarias como «Ver detalle»).

- Props: `variant`, `size` (`md` 44px / `sm` 36px), `icon` / `iconEnd` (nombre de `Pajaro.Icon`), `disabled`, y cualquier atributo de `<button>`.
- Texto: verbo primero, sentence case, ≤3 palabras: «Elegir vuelo», «Crear alerta», «Comprar ahora».
- La flecha `arrowRight` solo en el botón que avanza el flujo.
