# Badge

Etiqueta de una o dos palabras para estado o ranking.

- Props: `tone` (`neutral`, `cielo`, `sol`, `success`, `danger`, `warning`), `icon`, `children`.
- `sol` es exclusivo de «Mejor opción» (una sola por lista) y se muestra en mayúsculas. Las variaciones de precio llevan siempre flecha (`arrowDown`/`arrowUp`) además del color.
