# Mark

El pájaro de Pájaro como SVG en línea; hereda `color` (por defecto `cielo`) o, con `tile`, dibuja el ícono de app completo en `brand-cielo` + `brand-sol`.

- Props: `size` (px, 24 por defecto), `tile` (ícono de app), `color` (cualquier token como `var(--…)`), `label` (texto accesible).
- Usalo como avatar de la IA, en títulos de «Por qué te lo recomiendo», loaders y estados vacíos. Para el logo completo usá los assets del grupo Logos.
- No: pájaro `sol` sobre fondo claro, rotarlo, animarlo hacia abajo.
